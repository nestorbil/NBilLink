# NBilLink
Nitro Autoteile — mobile Link-Seite

Это готовая мобильная страница для QR-кода и NFC. Откройте `index.html` двойным кликом — сервер или установка не нужны.

## Что уже добавлено

- Прямая кнопка **Auf Google bewerten** на вкладку отзывов Nitro Autoteile.
- Google Maps, WhatsApp, звонок, email, Instagram, TikTok, Facebook и существующий сайт.
- Контакты: Böttgerstraße 7, 13357 Berlin · +49 30 767 95 242 · info@nitroautoteile.de.
- Адаптация прежде всего для телефона; на компьютере страница остаётся компактной.
- CSS-анимация логотипа только при открытии страницы и появление кнопок во время прокрутки. Анимации автоматически отключаются для пользователей с системной настройкой «уменьшить движение».

## Редактирование

Откройте `config.js`. Там в одном месте находятся все ссылки, номер, email, адрес и текст. Не нужно менять HTML или CSS.

Оригинальный логотип сохранён локально как `nitro-autoteile-logo.jpg`. Его путь уже подключён в `config.js`; сайт не зависит от интернета для показа логотипа.

## Google-отзывы

Ссылка уже ведёт в раздел отзывов конкретной карточки Nitro. В будущем, при доступе к Google Business Profile, откройте пункт **Um Bewertungen bitten** и замените `googleReviews` на выданную Google короткую ссылку — она сразу откроет форму написания отзыва.
